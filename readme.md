This project is made to show entry level data analysis skills

Data set: The Data set "ecommerce_dataset_updated.csv" is downloaded from kaggle

Skill used: Tools such as Python, MYSQL, Excel and Power BI are displayed in this project

#Second step: The dataset is imported to MYSQL. The columns were first cleaned so that SQL can read it. Then some basic Excel code were written to Anaylse the data. The screenshot of the SQL code are taken and save in SQL SS folder.

#Third step: The save Excel data were anaylse using Pivot table. The screenshot of Pivot table is save as Pivot table SS

#Fourth step: Finally, dashboard were created using Power BI.

#Note: The dataset is very limited and the date of purchase is all the same. For the said reason, insight such as monthly return were not taken
